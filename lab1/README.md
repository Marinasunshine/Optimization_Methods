## Практическое задание по теме «Задачи линейного программирования»
В рамках данной работы вы закрепите навыки работы с математической постановкой задачи линейного программирования, получения из нее допустимого канонического вида и ее решения с помощью симплекс-метода.

## Что дано на входе?
Общая задача линейного программирования – математическая запись: целевая функций (он же критерий эффективности); ограничения

## Что необходимо сделать или шаги решения?
1. Привести задачу к каноническому виду.
2. Сформулировать вспомогательную задачу.
3. Решить вспомогательную задачу.
4. Перейти к основной задаче (если есть возможность).
5. Решить основную задачу.
6. Записать ответ в форме: оптимальная точка , значение целевой функции в оптимальной точке.

## Функционал
* `step_compact(matrix, b, c_row, q, basis_vars, free_vars)` выполняет один шаг перерасчёта симплекс-таблицы 
* `solve(target_func_text, constraints_list, optimization_mode)` основная функция: приводит задачу к каноническому виду, решает вспомогательную задачу для поиска начального базиса и находит оптимальную точку целевой функции
* `if __name__ == "__main__":` блок консольного ввода данных пользователем и запуска решения

## Входные данные
* **Формат:**
  * **Первая строка:** коэффициенты при переменных в целевой функции через пробел
  * **Вторая строка:** направление оптимизации (`min` или `max`)
  * **Третья строка:** количество ограничений
  * **Остальные строки:** коэффициенты при переменных в ограничениях через пробел, знак (`<=`, `>=`, `=`), коэффициент справа

* **Пример:**
  ```text
  2 3 1 4
  min
  3
  1 2 1 0 <= 7
  0 1 1 1 = 5
  1 0 0 1 >= 3
